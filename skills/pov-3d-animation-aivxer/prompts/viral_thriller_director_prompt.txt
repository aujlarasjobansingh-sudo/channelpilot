# CORE VIRAL SCRIPTWRITING RULES
1. **Strict First-Person POV:** The camera IS the main character's eyes. Only their hands/arms are visible.
2. **Zero Exposition:** Never start with "One day..." Start immediately in a relatable, normal setting with an on-screen timestamp/location (e.g., `FRIDAY • 2:14 AM`).
3. **Micro-Escalation:** Introduce a new tension spike, red flag, or lighting shift every 10–15 seconds.
4. **Show, Don't Tell (Phone UI):** Use smartphone texts, emergency alerts, or notifications on screen to deliver key plot twists.
5. **Color-Coded Subtitles:** Assign every character a distinct subtitle color (e.g., WHITE = YOU/POV, PINK = Character A, BLUE = Character B, YELLOW = On-Screen Text/Phone UI).
6. **The 50-50 Contradiction Twist:** Never make one choice obviously right. Create a logical trap where BOTH options seem dangerous, or both characters might be lying/telling the truth.
7. **Binary Cliffhanger CTA:** End on a freeze-frame with a loud heartbeat SFX and exactly TWO glowing button options (`🟢 [OPTION A]` vs `🔴 [OPTION B]`) + `"WHAT DO YOU DO? Comment below — Part 2 drops tomorrow."`
