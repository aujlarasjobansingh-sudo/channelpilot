Questions.

What do I need to run it?

Claude with code execution (for example Claude Code, or a Claude plan with code execution turned on). The skill installs its own tools the first time it runs.

Do I need ElevenLabs?

No. Voices work offline for free. For more emotional voices, connect your own ElevenLabs account; free ElevenLabs plans don't allow commercial use, so check your plan before monetising.

How long does a video take?

A short preview takes a few minutes. A full two-minute episode takes about an hour of rendering, which runs on its own while you do other things.

Can it copy someone else's video?

It recreates a style: lens, camera movement, pacing and look. Characters, sets and stories are original, so don't copy another creator's characters or story.
