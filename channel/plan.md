# Channel Plan

## CURRENT CONCEPT (Nov 19, 2026): "In This World..." long stories
Inspired by viral Roblox "In this town..." POV videos, but long-form (20–30 min) and 2D animated.
- Second-person narration: "In this world, har insaan ke paas ek power hoti hai... lekin tumhare paas nahi."
- World has an anime-style vibe (inspired by popular anime/web-novel tropes), but story, characters,
  names, places, power system and twists are OUR OWN. Not a renamed copy of any anime's plot or world.
- Same video format as below (hook → subscribe → acts → value points → "agla world kaun sa?").
- **Language:** videos and scripts in ENGLISH (owner gives instructions in Hindi).
- **No subtitles/captions.** On-screen text only for key moments (e.g. the "IN THIS WORLD" title), clean premium typography.
- **Voice:** ElevenLabs only for the final full video. Previews: no paid voice.
- **Quality bar:** premium, not low-effort: rich saturated lighting, depth, bloom, AO, DOF, color grade, detailed world.
- **Hero mascot:** red t-shirt with white bolt, black spiky hair, blue jeans, white shoes (owner approved the look).
- **First world:** superhero city with monster attacks (One Punch Man *vibe* only; own names, ranks, monsters).
- **Script opening rule:** start with a "What happens if you..." hook. Reveal NOTHING at the start
  (no source, no ending, no big twist). Subscribe ask right after the hook.
- **Visual direction:** 3D backgrounds + 3D characters, Roblox-story-video feel (owner's reference:
  https://youtu.be/FXJO5fIHidQ — could not be opened from the cloud session; screenshots needed).
  Plan: our own low-poly / blocky 3D characters (not Roblox avatars) in stylized 3D worlds,
  built with three.js + Remotion.

# Earlier plan — Anime / Web Novel Story Explainer (2D animated)

Status: niche = anime-style novels (web novels, light novels, Chinese/Korean novels).
First topic and style not final yet (Nov 19, 2026).

## Format (every video, 20–30 min)
1. **Hook (0:00–0:45):** fast montage of the story's biggest moments as questions. Never give the ending.
2. **Subscribe ask (0:45–0:55):** one short line, right before the story starts.
3. **Story in 4–5 acts:** retold in our own voice. Same plot, more drama, a cliffhanger at
   the end of every act (re-hook every 3–5 min).
4. **Value points inside the story:** "Yahan dhyaan do..." pauses: hidden meaning, power-system
   breakdown, foreshadowing, character psychology. This makes it ours, not a plain recap.
5. **Ending:** short wrap-up + **ask viewers in a question which novel they want next**
   ("Comment karo agli video kis novel pe chahiye"). Pin that question as a comment too.

## Safety rules for this niche (all these novels are copyrighted)
- Never use manhwa/webtoon panels, donghua/anime clips, official covers or official art.
- All characters and scenes drawn in our own style; own script, own narration, own commentary.
- Never upload translated chapters or read the novel text word for word.

## Visual style
- **Shadow Ink (recommended):** dark ink-wash backgrounds, characters as silhouettes with glowing
  eyes and glowing power effects, layered parallax, one accent colour per character.
  Fits dark-fantasy novels and is fully doable with code animation.
- Detailed anime faces are NOT possible with code-only animation; would need an image-generation
  tool, which this setup doesn't have yet.
